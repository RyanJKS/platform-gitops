# Repository instructions

## Documentation maintenance

For every change, assess whether readers need updated documentation. When a change
affects behavior, setup, configuration, interfaces, architecture, or operations,
read and follow [.agent/skills/documentation-maintainer/SKILL.md](.agent/skills/documentation-maintainer/SKILL.md)
and include the relevant documentation updates in the same task. Use the skill
for documentation-only work as well. If no documentation update is needed, do not
create a cosmetic edit to satisfy this instruction.

Keep `mkdocs.yml`, `docs/`, and the TechDocs annotation in `catalog-info.yaml`
consistent. Report the documentation checks performed and any check that could
not run. Do not claim a successful TechDocs build without running it.
