# Security

## Reporting a vulnerability

Do not include vulnerabilities, credentials, or sensitive data in public issues or pull requests.

If private vulnerability reporting is enabled, use **Security → Report a vulnerability** on GitHub. Otherwise, contact the repository owners through an established private channel. Include affected versions, reproduction steps, and the potential impact without exposing live secrets.

## Maintenance

Security fixes target the latest code on `main` unless maintainers document supported release versions here. Maintainers should enable private vulnerability reporting and add a dedicated security contact before external distribution.
